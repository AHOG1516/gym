# 💪 내 운동 기록

헬스장에서 휴대폰으로 그날 루틴의 무게와 횟수를 입력하면 **내 구글 시트에 자동 저장**되는 개인용 웹앱입니다.
홈 화면에 추가하면 앱처럼 전체 화면으로 열립니다. 서버 비용은 없습니다.

```
휴대폰 앱 화면 (GitHub Pages)  →  Apps Script  →  내 구글 시트
```

---

## 처음 설정하기 (약 15분, 한 번만)

PC에서 1~3단계를 하고, 휴대폰에서 4단계를 하면 편합니다.

### 1단계. 구글 시트와 저장 서버 만들기

1. [구글 드라이브](https://drive.google.com)에서 **새로 만들기 → Google 스프레드시트**를 누르고, 이름을 `운동 기록`으로 바꿉니다.
2. 시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다. 새 탭이 열립니다.
3. 편집 칸에 있는 내용을 **모두 지우고**, 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 **통째로 복사해 붙여넣습니다.**
4. 위쪽의 💾(저장) 아이콘을 누릅니다.
5. 위쪽 도구 줄의 함수 선택 칸에서 **`setup`** 을 고르고 **▶ 실행**을 누릅니다.
   - "승인 필요" 창이 뜨면 **권한 검토 → 내 구글 계정 선택**을 누릅니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용**을 누릅니다. 내가 만든 스크립트를 내 계정에 허용하는 것이라 괜찮습니다.
6. 아래쪽 **실행 로그**에 `TOKEN: ...` 줄이 나옵니다. 이 **토큰 값을 복사해 메모장에 적어 둡니다.**
   - 시트로 돌아가 보면 `sessions`, `sets`, `body`, `notes`, `routines`, `exercises`, `config` 탭이 생겨 있습니다.
   - `routines`·`exercises` 탭은 처음엔 비어 있고, 앱을 처음 연결할 때 기본 루틴(A/B)으로 자동으로 채워집니다.

> 토큰은 "내 시트에 쓸 수 있는 비밀번호"입니다. 다른 사람에게 보여 주거나 GitHub에 올리지 마세요.
> 나중에 다시 보려면: Apps Script 왼쪽 ⚙️ **프로젝트 설정 → 스크립트 속성 → TOKEN**.

### 2단계. 웹 앱으로 배포하기

1. Apps Script 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. "유형 선택" 옆 ⚙️ 를 눌러 **웹 앱**을 고릅니다.
3. 이렇게 설정합니다.
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포**를 누릅니다.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해 메모장에 적어 둡니다.

> "모든 사용자"로 해도 괜찮은 이유: 주소를 알아도 **토큰이 없으면 읽기·쓰기 모두 거부**되도록 만들어져 있습니다.

### 3단계. GitHub에 앱 올리기

1. [github.com](https://github.com)에 로그인하고 오른쪽 위 **+ → New repository**를 누릅니다.
2. 이름을 정하고(예: `gym`), **Public**을 고른 뒤 **Create repository**를 누릅니다.
3. 다음 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 이 폴더의 아래 항목을 **끌어다 놓습니다.**
   - `index.html`, `routines.json`, `manifest.webmanifest`, `sw.js`, `README.md`
   - `icons` 폴더, `apps-script` 폴더
5. 아래 **Commit changes**를 누릅니다.
6. 저장소의 **Settings → Pages**로 가서, **Branch**를 `main` / `/ (root)`로 고르고 **Save**를 누릅니다.
7. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다. (`https://내아이디.github.io/gym/`)

> 저장소에는 웹 앱 URL과 토큰이 **들어 있지 않습니다.** 두 값은 휴대폰 안에만 저장됩니다. 앞으로도 올리지 마세요.

### 4단계. 아이폰에 설치하고 연결하기

**순서가 중요합니다. 먼저 홈 화면에 추가하고, 그 앱 안에서 연결 설정을 하세요.**
(아이폰은 Safari와 홈 화면 앱의 저장 공간이 따로라서, Safari에서 입력한 설정은 앱으로 넘어오지 않습니다.)

1. 아이폰 **Safari**로 3단계의 주소를 엽니다.
2. 아래쪽 **공유 버튼(□↑) → 홈 화면에 추가 → 추가**를 누릅니다.
3. 홈 화면에 생긴 **운동 기록** 아이콘을 눌러 엽니다.
4. 설정 화면이 나옵니다. **웹 앱 URL**과 **토큰**을 붙여넣습니다.
   - PC에 적어 둔 값은 카카오톡 "나에게 보내기"나 메모 앱으로 옮기면 편합니다.
5. **연결 테스트**를 눌러 "✅ 연결됐어요!"가 나오면 **저장**을 누릅니다.

끝입니다. 이제 입력하면 1~2초 안에 시트에 들어갑니다.

(안드로이드: Chrome으로 주소를 열고 ⋮ → **홈 화면에 추가**.)

## 쓰는 법

- **오늘 운동**: 앱을 열면 오늘 할 루틴이 자동으로 골라집니다(지난번의 다음 루틴). 무게를 맞추고 세트를 끝낼 때마다 **✓ N회** 버튼을 누르면 횟수가 채워지고 휴식 타이머가 시작됩니다. 목표보다 적게 했으면 숫자를 직접 고치세요.
- **한 종목씩 / 전체**: 기본은 지금 할 운동 하나만 크게 보여 줍니다. **다음 운동 ▶** 버튼이나 ◀ ▶, 점을 눌러 옮겨 다닙니다. "전체"를 누르면 모든 운동이 한 화면에 나옵니다.
- **완료되는 방법**: 권장 세트(예: 3세트)의 횟수를 모두 적으면 번호가 초록 ✓로 바뀌고 완료됩니다. 따로 누를 완료 버튼은 없습니다. 카드에 `2/3세트`처럼 진행이 보입니다.
- **무게는 세트 줄마다 적습니다.** 1세트 무게를 적으면 아래 세트도 같은 무게로 채워지고, 2세트를 고치면 그 아래만 따라 바뀝니다. 세트마다 무게를 올려 가도 그대로 기록됩니다. −/+ 로 한 단계씩 조절할 수 있고, `0`은 "기구 무게만"입니다.
- **+ 세트 추가**: 권장 세트보다 더 했을 때 누르면 줄이 하나 더 생깁니다(`+4`, `+5`…). 안 적어도 완료에는 영향이 없습니다.
- **건너뛰기**: 그날 안 한 운동은 이 버튼을 누릅니다. 기록에 남지 않고 다음 추천에도 쓰이지 않습니다. 0kg으로 채워 넣지 마세요.
- **머신 세팅 메모**: 카드의 ⚙️ 줄을 눌러 의자 높이·핀 위치를 적어 두면, 그 운동을 할 때마다 계속 보입니다.
- **운동별 메모**: 세트 줄 아래의 메모 칸에 그날 그 운동에 대한 메모(자세, 느낌 등)를 적습니다. 다음에 같은 운동을 할 때 "📝 지난번 메모"로 보입니다. 맨 아래 "오늘 전체 메모"는 컨디션처럼 그날 전체에 대한 메모용입니다. 운동별 메모는 `sessions` 탭의 기록 안에 저장됩니다.
- **세트별 난이도**: 세트를 마치면 그 줄 바로 아래에 쉬움·적당·힘듦이 나타납니다. 세트마다 하나씩 누를 수 있고, 같은 것을 다시 누르면 지워집니다(안 눌러도 됩니다). 다음 추천은 가장 무거운 세트의 난이도를 봅니다. 난이도는 `sessions` 탭에만 저장되고 `sets` 탭에는 나오지 않습니다.
- **🔄 대체**: 머신이 차 있을 때 그날만 다른 운동으로 바꿉니다. 후보에서 고르거나 이름을 직접 적으세요. 같은 이름으로 다시 대체하면 지난 기록이 이어집니다.
- **체중**: 위쪽 체중 칸에 적으면 날짜별로 저장되고, 성장 탭에 변화가 나옵니다.
- **이번 주 ●●○ 2/3회 · 2주차**: 이번 주(월~일) 운동 횟수와 프로그램 주차입니다.
- **추천 배지** — 기준은 지난번에 **목표 횟수를 채운 세트 중 가장 무거운 무게**(최고 세트)입니다. 추가 세트도 포함합니다.
  - **= 지난번 최고 무게로 전 세트**: 세트마다 무게를 올려서 최고 무게는 한두 세트만 했을 때. 다음엔 그 무게로 권장 세트를 전부 채워 봅니다.
  - **↑ 증량**: 최고 무게로 권장 세트를 전부 목표 횟수만큼 했을 때. 횟수 범위가 있는 운동(예: 12~15회)은 "쉬움"을 눌렀다면 최소 횟수만 채워도 증량.
  - **= 같은 무게로 / 한 단계 낮춰서 (지난번 힘듦)**: 최고 무게 세트에 "힘듦"을 눌렀으면 올리지 않습니다. 최고 무게로 전 세트를 못 채웠다면 그 아래 성공한 무게로 내려갑니다.
  - **↓ 감량**: 목표를 채운 세트가 없고, 가장 무거운 세트가 목표보다 2회 넘게 모자랐을 때.
  - 추천은 시작값일 뿐이니 무게 칸에서 언제든 고쳐도 됩니다.
- **기록**: 지난 운동 목록. 누르면 열어서 고칠 수 있고, **삭제**는 두 번 눌러야 지워집니다.
- **성장**: 체중 변화, 운동별 최근 무게와 변화 그래프.
- 오른쪽 위 글자가 저장 상태입니다. **저장됨 ✓** 이면 시트까지 들어간 것입니다. 누르면 바로 동기화합니다.

### 알아 둘 점 (아이폰)

- **휴식 타이머 알림은 소리 + 화면 깜빡임**입니다. 아이폰 웹앱은 진동을 쓸 수 없습니다.
  - 무음 모드이거나 음량이 0이면 소리가 안 날 수 있습니다. 화면의 초록색 **GO!** 를 확인하세요.
  - 휴식 중에는 화면이 꺼지지 않게 해 두었습니다(지원하는 iOS 버전에서만). 다른 앱으로 넘어가 있으면 알림 소리는 나지 않고, 돌아왔을 때 남은 시간이 정확히 표시됩니다.
- **인터넷이 끊겨도 입력은 됩니다.** 상단에 "⚠️ 오프라인, 나중에 전송"이 뜨고, 연결되면 자동으로 보냅니다.

## 구글 시트 보는 법

| 시트 탭 | 용도 | 직접 고쳐도 되나 |
|---|---|---|
| `sessions` | 앱이 읽고 쓰는 운동 기록 원본. 하루에 한 줄 | ✕ 앱의 "기록" 탭에서 고치세요 |
| `sets` | 사람이 보기 좋게 풀어 쓴 표. 세트 하나에 한 줄. 피벗·차트는 이걸로 | ✕ 저장할 때마다 앱이 다시 씁니다 |
| `body` | 날짜별 체중 | ○ |
| `notes` | 운동별 머신 세팅 메모 | ○ |
| `routines` | 루틴 목록 (제목, 색, 워밍업, 마무리) | ○ 아래 설명 참고 |
| `exercises` | 루틴별 운동 목록 (세트 수, 횟수, 휴식, 꿀팁 등) | ○ 아래 설명 참고 |
| `config` | 주간 목표 횟수 등 | ○ `value` 열만 |

- 시트에서 고친 내용은 앱에서 **오른쪽 위 상태 글자를 누르면**(또는 ⚙️ → 지금 동기화) 반영됩니다.
- 차트나 피벗은 **새 시트 탭**에 만드세요. 위 탭들 안에 열을 추가하거나 순서를 바꾸지 마세요.

### `config` 탭

| key | 뜻 |
|---|---|
| `weeklyGoal` | 일주일에 운동할 횟수 (기본 3) |
| `programStart` | 프로그램 시작일. 예: `2026-11-16`. 비워 두면 첫 기록 날짜부터 주차를 셉니다 |
| `changeWeek` | 이 주차가 되면 "루틴을 바꿀 때예요" 알림 (기본 5). 루틴을 바꾼 뒤에는 다음 교체 주차로 고치거나 `0`으로 끄세요 |

## 루틴 바꾸기 (예: 5주차에 상·하체 분할로)

루틴은 구글 시트의 **`routines`** 탭과 **`exercises`** 탭에서 표로 고칩니다. 고친 뒤 앱에서 동기화하면 반영됩니다.

**`exercises` 탭 — 한 줄이 운동 하나, 위에서 아래 순서대로 앱에 나옵니다.**

| 열 | 적는 법 |
|---|---|
| 루틴 키 | 이 운동이 속한 루틴. 예: `A`, `B`, `상체1` |
| id | **새 운동은 비워 두세요.** 동기화하면 자동으로 채워집니다. 이미 있는 값은 바꾸지 마세요(지난 기록과 이어 주는 이름표) |
| 운동 이름, 부위 | 화면에 보이는 글자. 이름은 나중에 바꿔도 됩니다 |
| 세트 수 | 예: `3` |
| 횟수 표시 | 화면에 보이는 글자. 예: `10`, `12~15`, `10 (한쪽씩)` |
| 최소 횟수 / 목표 횟수 | 추천 계산에 쓰는 숫자. 예: `12` / `15`. 비우면 "횟수 표시"에서 읽습니다 |
| 시작 무게 안내 | 첫 기록 때 보여 줄 글자 |
| 휴식(초) | 예: `120` |
| 증량 단위(kg) | 예: 하체 `5`, 나머지 `2.5` |
| 대체 운동 | 쉼표로 구분. 예: `핵 스쿼트 머신, 스쿼트 머신` |
| 꿀팁 | 한 줄에 하나, `라벨: 내용` 형식. 라벨이 세팅·꿀팁·주의면 색 태그가 붙습니다. 칸 안에서 줄바꿈은 Ctrl+Enter |

**`routines` 탭 — 한 줄이 루틴 하나.**

| 열 | 적는 법 |
|---|---|
| 루틴 키 | `exercises` 탭에서 쓴 것과 같은 글자 |
| 제목 / 버튼 글자 | 성장 탭 제목 / 선택 버튼 글자(비우면 `키 day`) |
| 색 | 예: `#2563eb`(파랑), `#059669`(초록), `#7c3aed`(보라), `#d97706`(주황) |
| 지난 루틴이면 TRUE | `TRUE`를 적으면 선택 버튼에서는 사라지고 "기록"·"성장" 탭에는 계속 보입니다 |
| 워밍업 / 마무리 | 한 줄에 하나 |

알아 둘 점

- **지난 루틴은 줄을 지우지 말고 `TRUE`만 적으세요.** 줄을 지우면 그 기록은 시트에는 남지만 앱에서 내용을 열 수 없습니다.
- 새 루틴에서도 같은 운동이면 **같은 id를 복사해** 쓰면 무게 추천이 이어집니다.
- 루틴은 2개가 아니어도 됩니다. 4개면 버튼 4개가 생기고, `routines` 탭의 순서대로 돌아가며 추천됩니다.
- 잘못 적은 줄이 있으면 앱 위쪽에 빨간 안내가 뜨고, ⚙️ 설정에서 몇 번째 줄인지 알려 줍니다. 그 줄만 빼고 나머지는 정상으로 나옵니다.
- `exercises` 탭을 통째로 비우면, 앱을 다시 열 때 마지막으로 쓰던 루틴으로 다시 채웁니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 연결 테스트에서 "토큰이 달라요" | 토큰 앞뒤에 빈칸이 들어가지 않았는지, Apps Script의 스크립트 속성 `TOKEN`과 같은지 |
| "연결하지 못했어요" | 주소가 `/exec`로 끝나는지(`/dev` 아님), 배포의 액세스가 **모든 사용자**인지, 인터넷이 되는지 |
| `Code.gs`를 고쳤는데 그대로 | **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포.** 주소는 그대로 유지됩니다. "새 배포"를 누르면 주소가 바뀌니 주의 |
| 다른 기기에서 기록이 안 보임 | 오른쪽 위 상태 글자를 눌러 동기화. 그 기기에도 URL·토큰을 입력했는지 |
| 토큰이 노출된 것 같음 | 스크립트 속성의 `TOKEN` 값을 새 글자로 바꾸고, 앱 설정(⚙️)에 새 토큰 입력 |
| 앱 화면이 옛날 버전 | 앱을 완전히 닫았다가 다시 열기(두 번 정도) |

## 파일 구성

```
index.html             앱 화면 (전부 이 한 파일)
routines.json          기본 루틴 (처음 연결할 때 시트의 루틴 표를 채우는 데만 씀)

sw.js                  인터넷이 없어도 앱이 열리게 하는 캐시 (API 요청은 캐시하지 않음)
icons/                 앱 아이콘
apps-script/Code.gs    구글 시트 저장 서버 (Apps Script에 붙여넣는 코드)
```
